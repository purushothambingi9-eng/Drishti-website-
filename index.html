About Drishti

Drishti is a student project designed to help visually impaired children detect obstacles while walking.

The project aims to make movement safer and more comfortable through simple assistive technology.

How It Works

📷 Camera / Sensor detects an obstacle.

⚙️ Controller processes the information.

🔊 Speaker gives an audio alert.

🚶 The user can become aware of the obstacle.

Features

👓 Smart Glasses

Portable assistive design.

📷 Obstacle Detection

Detects objects in the user's path.

🔊 Audio Alert

Provides an alert when an obstacle is detected.
